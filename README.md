## NC-local-1D-velocity

Local 1D velocity models for New Caledonia. 

This is the archive of 1D velocity models derived from local earthquakes and from Rayleigh wave dispersion curves by Chin et al (2025).

## Table of contents

[velocity1D.txt](velocity.txt)- Updated 1D Vp and Vs models using local earthquakes in southern New Caledonia.

[from_Rayleigh_group](./vs/from_Rayleigh_group)- Smoothed 1D Vs models for each group derived from Rayleigh wave group velocity dispersion curves.

[from_Rayleigh_phase](./vs/from_Rayleigh_phase)- Smoothed 1D Vs models for each group derived from Rayleigh wave phase velocity dispersion curves.
